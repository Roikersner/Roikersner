# תיקיית עריכת רילז עם Claude

בנוי לפי "המדריך המלא לעריכת סרטונים עם Claude Code". מצלמים בטלפון, מעלים, ומקבלים ריל ערוך:
בלי שתיקות, בלי גמגומים, בלי טייקים כפולים, עם כתוביות בעברית וקאבר.

## מה יש כאן
- `CLAUDE.md`: קובץ החוקים (נספח ג במדריך) + הכלים המוכנים ומה למדנו בבדיקות. Claude קורא אותו לבד.
- `tools/`: כלי העריכה (בדיקת סרטון, תמלול, חיתוך, קובץ אישור, כתוביות, בדיקה לפני מסירה, קאבר).
- `fonts/`: הפונט Heebo, במשקלים 800 ו-900.
- `להעלאה/`, `לאישור/`, `מוכן/`, `work/`: התיקיות של התהליך. סרטונים לא נשמרים ב-git.
- `setup.sh`: מתקין הכל. מריצים פעם אחת (או Claude מריץ לבד).

## איך עורכים ריל
1. מעלים את הסרטון: מצרפים אותו בצ'אט עם Claude (או, במחשב, שמים אותו ב-`להעלאה/`).
2. שולחים:

   > סיימתי לצלם. הסרטון בתיקייה להעלאה.
   > תוריד שתיקות, גמגומים, עצירות ומשפטים כפולים.
   > צילמתי כמה טייקים לכל משפט, והאחרון הוא הטוב.
   > שים לב לשמור את הסוף של כל מילה, שלא ייחתך.
   > לפני שאתה חותך, תראה לי מה יורד.

3. "נראה טוב, תחתוך" → מתקנים את קובץ התמלול → "אישרתי" → בוחרים סגנון כתוביות →
   "תכין תמונת קאבר" → "A" או "B".

הקבצים הסופיים: `מוכן/<שם הריל>/reel.mp4` (לאינסטגרם), `reel-phone.mp4` (לצפייה), `cover-A.jpg` / `cover-B.jpg`.
